## 🚀 Featured project

### 💸 SplitSol — smart expense splitting for friends, housemates & teams

<a href="https://splitsol.co"><img src="https://img.shields.io/badge/Live-splitsol.co-6C4DF6?style=flat-square&logo=googlechrome&logoColor=white" alt="Live site" /></a>
<img src="https://img.shields.io/badge/Flutter-02569B?style=flat-square&logo=flutter&logoColor=white" alt="Flutter" />
<img src="https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=black" alt="Firebase" />
<img src="https://img.shields.io/badge/status-in%20development-8B5CF6?style=flat-square" alt="Status" />

A real-time, mobile-first shared ledger. You add an expense once; everyone's balance
updates everywhere, instantly, and the arithmetic is always exact.

| | |
|---|---|
| **Stack** | Flutter · Firebase Auth · Cloud Firestore · Cloud Functions · FCM · Crashlytics |
| **Architecture** | Strict clean architecture — BLoC + `get_it`/`injectable`, one feature per module |
| **Money** | All amounts stored in **minor units** (integers). No floats, no rounding drift. |
| **Balances** | Idempotent delta projection — replaying an event never double-counts |
| **Server** | Governance-critical writes go through callable functions, guarded by security rules |
| **Extras** | Friends graph, hidden 1-on-1 groups, invite search over sealed hashed contacts, push notifications, 14-day account-deletion grace window |

> Every operational area has its own markdown doc, enforced in review. If it ships, it's
> documented.
