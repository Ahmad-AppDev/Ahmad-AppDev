### &nbsp;💸&nbsp; SplitSol &nbsp;·&nbsp; <sub>smart expense splitting</sub>

A real-time shared ledger. Add an expense once; everyone's balance settles everywhere, instantly, and the arithmetic is always exact. &nbsp;→&nbsp; **[splitsol.co](https://splitsol.co)**

| | |
|:--|:--|
| **Money** | stored in minor units as integers — no floats, no rounding drift |
| **Balances** | idempotent delta projection — replaying an event never double-counts |
| **Server** | governance-critical writes go through callable functions, guarded by rules |
| **Privacy** | invite search over sealed hashed contacts · 14-day deletion grace window |
| **Stack** | Flutter · Firebase Auth · Firestore · Cloud Functions · FCM · Crashlytics |
